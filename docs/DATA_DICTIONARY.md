# Data Dictionary

The canonical schema for this project is generated by the pipeline into `docs/data_dictionary.csv`.

Key guarantees:

- all source columns are normalized to one canonical naming scheme
- `accident_date` is parsed as a datetime
- `time` is parsed from `HH:MM:SS`
- `accident_severity` is normalized so typo variants like `Fetal` become `Fatal`
- engineered fields such as `year`, `month`, `day`, `hour`, `casualties_per_vehicle`, and `severity_label` are created consistently in code rather than ad hoc in notebooks
